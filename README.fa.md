# مبانی کامپیوتر و مهارت‌های دیجیتال

> دوره‌ای آموزشی با هدف افزایش سواد دیجیتال، آموزش مهارت‌های پایه کامپیوتر و آشنایی با هوش مصنوعی و برنامه‌نویسی.

## معرفی

این مخزن شامل مستندات، منابع و محتوای آموزشی دوره **مبانی کامپیوتر و مهارت‌های دیجیتال** است.

این دوره برای افراد مبتدی طراحی شده و تلاش می‌کند با آموزش مفاهیم پایه، مهارت‌های عملی و فناوری‌های روز، هنرجویان را برای استفاده صحیح و آگاهانه از کامپیوتر و ابزارهای دیجیتال آماده کند.

---

## سرفصل‌های دوره

### ۱. آشنایی با کامپیوتر

- کامپیوتر چیست؟
- دستگاه‌های ورودی و خروجی
- آشنایی مقدماتی با سخت‌افزار
- روشن و خاموش کردن صحیح سیستم
- ورود به دنیای نرم‌افزار

### ۲. کار با سیستم‌عامل

- آشنایی با محیط ویندوز
- فایل‌ها، پوشه‌ها، مسیرها و فرمت‌های مختلف
- فشرده‌سازی و استخراج فایل‌ها
- نصب و حذف نرم‌افزار
- میانبرهای کاربردی صفحه‌کلید

### ۳. اینترنت و امنیت دیجیتال

- موتورهای جست‌وجو و جست‌وجوی صحیح
- تشخیص وب‌سایت‌های معتبر
- آشنایی با ویروس‌های رایانه‌ای
- تهدیدات امنیتی و روش‌های مقابله
- مدیریت رمز عبور
- آشنایی با مفاهیم هک و مهندسی اجتماعی

### ۴. نرم‌افزارهای اداری

- آشنایی با مجموعه Office
- Microsoft Word
- Microsoft PowerPoint
- Microsoft Excel
- LibreOffice و سایر ابزارهای کاربردی

### ۵. هوش مصنوعی

- آشنایی با هوش مصنوعی
- استفاده صحیح از ابزارهایی مانند ChatGPT
- توانایی‌ها و محدودیت‌های مدل‌های هوش مصنوعی
- اصول پرامپت‌نویسی

### ۶. آشنایی با برنامه‌نویسی

- برنامه‌نویسی چیست؟
- آشنایی با زبان‌های برنامه‌نویسی
- معرفی Python
- نصب ابزارهای موردنیاز
- نوشتن اولین برنامه
- دستورات مقدماتی
- ساخت چند برنامه ساده
