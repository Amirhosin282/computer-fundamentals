# Computer Fundamentals & Digital Skills

> An educational course designed to build practical digital literacy and introduce learners to the world of computers, artificial intelligence, and programming.

## About

This repository contains the documentation and educational materials for the **Computer Fundamentals & Digital Skills** course.

The course is designed for beginners with little or no prior experience and focuses on developing essential computer skills required for education, work, and everyday life.

The program combines theoretical concepts with practical exercises to help students confidently use modern digital technologies.

---

## Course Outline

### 1. Introduction to Computers

- What is a computer?
- Input and output devices
- Basic hardware concepts
- Powering on/off a computer
- Introduction to software

### 2. Operating Systems

- Windows basics
- Files, folders, and file formats
- Compression and archive management
- Installing and removing software
- Useful keyboard shortcuts

### 3. Internet & Digital Security

- Search engines and effective searching
- Recognizing trustworthy websites
- Computer viruses
- Digital threats and protection
- Password management
- Hacking and social engineering awareness

### 4. Office Applications

- Introduction to Office suites
- Microsoft Word
- Microsoft PowerPoint
- Microsoft Excel
- LibreOffice and other productivity tools

### 5. Artificial Intelligence

- Introduction to AI
- Using tools such as ChatGPT
- AI capabilities
- AI limitations
- Prompt engineering fundamentals

### 6. Introduction to Programming

- What is programming?
- Programming languages
- Introduction to Python
- Installing development tools
- Writing the first program
- Basic Python syntax
- Simple practical programs
